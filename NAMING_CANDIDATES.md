## 1. Selected Project Name: **Galiot**

- **Project Name**: **Galiot**
- **Etymology**: In naval history, a *galiot* (or *galeot*) was a smaller, agile, lightweight sailing craft developed alongside galleons by Mediterranean and Atlantic shipwrights. Designed for swift maneuvers, coastal operations, and shallow waters where heavy galleons would run aground.
- **The Connection to Galeon**: Direct historical and linguistic cousin from the same shipbuilding lineage, sharing the `Gale-` / `Gali-` root.
- **Tagline**: *"Chart your cloud from any browser."*
- **Role**: 
  - **Galeon**: The heavy native desktop flagship (Rust + Tauri + OS Keyring).
  - **Galiot**: The agile, 100% client-side web explorer (PGlite WASM Postgres + GitHub Pages).
